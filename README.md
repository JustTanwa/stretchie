# stretchie

A small WPF application that will alert you when it is time to take a break and stretch. 
It is designed to help you maintain good posture and reduce the risk of repetitive strain injuries while working at a computer.

## motivation
I wanted to learn something new, so I decided to create a small WPF application that would alert me when it was time to take a break and stretch. I opted for a desktop
application instead of a web or mobile app because I didn't want to have to keep a browser tab open or have my phone nearby while working. 
I also wanted to learn more about WPF and how to create a simple desktop application.

## features
- Customizable break intervals: You can set the time interval for breaks according to your preference.
- Notification alerts: The application will notify you when it's time to take a break, ensuring you don't miss it.
- User-friendly interface: The application has a simple and intuitive interface, making it easy to use for anyone.
- Lightweight and efficient: The application is designed to run in the background without consuming too many system resources.
